# SWYNEX Security Fundamentals Assessment

Security assessment performed against OWASP Juice Shop in an authorized
local Docker lab environment.

## Findings

- SQL Injection – Authentication Bypass
- DOM-Based Cross-Site Scripting

## Documentation

See `Security-Assessment-Report.md` for the detailed assessment,
evidence and recommended mitigations.

## Environment

- OWASP Juice Shop
- Docker
- Localhost
- Browser Developer Tools

All testing was performed only against the intentionally vulnerable
local training environment.
